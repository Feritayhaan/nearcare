# NearCare – En Yakın Hastane ve Eczane

YBS215 Introduction to Web Design dönem projesi.

Konumu kullanarak çevredeki hastane ve eczaneleri harita ve listede gösteren 3 sayfalık web sitesi.

- Sayfalar: `index.html`, `search.html`, `about.html`
- Teknolojiler: HTML5, CSS3, JavaScript, Geolocation API, Overpass API, Leaflet.js
- Veri: OpenStreetMap katkıcıları
- Yayın: GitHub Pages
