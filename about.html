Hakkında

Amaç

Acil durumlarda veya gece saatlerinde en yakın hastane ya da eczanenin nerede olduğunu bilmek zor olabilir. NearCare bunu birkaç tıkla gösterir.

Nasıl çalışır?

  1. Tarayıcının Geolocation API'si konumunu algılar (yalnızca izin verirsen).
  2. Yakındaki hastane ve eczaneler Overpass API ile OpenStreetMap'ten istenir.
  3. Sonuçlar mesafeye göre sıralanır, Leaflet haritasında ve listede gösterilir.

Gizlilik

Konumun yalnızca tarayıcında arama yapmak için kullanılır, NearCare tarafından saklanmaz.

Sınırlamalar

Veriler OpenStreetMap'ten gelir; bazı yerler eksik veya güncel olmayabilir. Nöbetçi eczane bilgisi uygulamada gösterilmez, arama sayfasındaki bağlantı ilçene göre resmi listeyi aramanı sağlar. Gitmeden önce eczaneyi arayın. Acil durumda 112.

Kullanılan teknolojiler

  • HTML5 (semantik etiketler), CSS3 (Flexbox, Grid, media query)
  • JavaScript (ES6, Fetch API), Geolocation API
  • Overpass API ve Nominatim (OpenStreetMap), Leaflet.js
  • Git, GitHub, GitHub Pages
